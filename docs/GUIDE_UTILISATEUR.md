# Guide utilisateur

## Parcourir la galerie

- **Accueil** (`/`) : presentation et oeuvres recentes.
- **Galerie** (`/galerie`) : catalogue complet avec recherche par mot-cle, auteur, technique, filtres par categorie/annee/disponibilite, et tri (recent, prix, annee).
- **Fiche oeuvre** (`/galerie/<reference>`) : auteur, titre, technique, dimensions, annee, commentaire, prix, disponibilite, categorie, collection, reference.

## Créer un compte

1. `/inscription` : nom, email, mot de passe (8 caracteres min., majuscule + minuscule + chiffre).
2. Confirmez votre email via le lien recu.
3. Votre compte est alors **"visiteur en attente de validation"** : vous pouvez consulter la galerie, mais pas encore envoyer de demande d'achat.
4. Un administrateur valide votre compte (statut **"client autorise"**) — vous recevrez alors la possibilite d'envoyer des demandes.

## Favoris

Sur toute fiche oeuvre, le bouton "Ajouter aux favoris" enregistre l'oeuvre dans votre espace `/compte` (onglet Favoris). Necessite d'etre connecte.

## Demander l'achat d'une oeuvre

Sur une fiche oeuvre **disponible**, une fois votre compte valide :

1. Cliquez sur "Demander l'achat".
2. Indiquez, si vous le souhaitez, un prix propose et un message.
3. Un administrateur traite votre demande (acceptee/refusee) et peut vous repondre — suivez le statut dans `/compte` (onglet Mes demandes).

## Mot de passe oublie

`/mot-de-passe-oublie` envoie un lien de reinitialisation par email, menant a `/reinitialiser-mot-de-passe`.

## Mode clair/sombre

Le bouton soleil/lune dans l'en-tete bascule le theme ; le choix est mémorisé.

## Protection des images — ce qu'il faut savoir

Les visuels affiches sont proteges (clic droit desactive, glisser-deposer desactive, impression desactivee sur les pages galerie, filigrane appose dynamiquement). **Aucune protection web ne peut empecher une capture d'ecran** (photo de l'ecran, capture logicielle, etc.) — ces mesures visent a decourager la copie/redistribution facile, pas a la rendre techniquement impossible.
